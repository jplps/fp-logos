* Λόγος

A Lisp interpreter that grows concept-by-concept as you read the FP canon.
From Church's λ-calculus through McCarthy's eval/apply to Hickey's persistent vectors —
each source adds a feature, each feature gets tests, each test proves the idea correct.

Two modules: =logos-scheme= (Chez Scheme, foundations + abstractions)
and =logos-clj= (Clojure, applied FP + data structures).

* Core Fundamentals

The curriculum distils five ideas that recur across every source:

1. *λ as universal substrate.* Church showed that a single construct — the anonymous function — encodes numbers, booleans, pairs, and control flow. Every subsequent layer (closures, continuations, monads) is a variation on this theme.
2. *Eval/apply duality.* McCarthy's insight: a language is defined by the interplay of an evaluator that dispatches on syntax and an applicator that dispatches on procedure type. The Λόγος evaluator makes this loop explicit, then extends it with tail calls, macros, and effects without breaking the core contract.
3. *Denotation over mechanism.* Landin's principle: every syntactic form denotes a value. The evaluator is an operational realisation of a denotational semantics. CPS is an alternative operational strategy for the same denotations.
4. *Composition through algebraic laws.* Backus's combinator algebra, the monad laws, functor composition, red-black invariants — correctness in FP is proved by showing that composition preserves structure. Property tests encode these laws.
5. *Persistence through structural sharing.* Okasaki and Hickey demonstrate that immutable data structures match mutable ones in practical performance by sharing unchanged substructure. The persistent vector trie is the canonical example.

* Code Standards

- *No comments.* Docstrings only — every public function documents what, parameters, returns, complexity.
- *80 char lines.* 15-line max function bodies. 2 levels max =let= nesting.
- *Property tests* for every algebraic structure (monad laws, heap ordering, red-black balance, combinator laws, queue FIFO, vector persistence).
- *One commit per source/concept:* =07: CPS transform — add cps.ss with transformer and round-trip tests=.
- *Pure functions by default.* Effectful functions suffixed with =!=, documented, pushed to boundaries.

* Testing

Three layers, applied across both modules:

1. *Example tests* — golden inputs/outputs, minimum 5 per source.
2. *Property tests* — algebraic laws and invariants. Scheme: custom generators. Clojure: =test.check= (100–200 runs per property).
3. *Self-hosting test* — end of Phase 2, the Scheme interpreter evaluates its own =eval=.

Running tests:

#+begin_src shell
cd scheme && make test       # all Scheme suites
cd clj && clj -M:test        # all Clojure suites
#+end_src
